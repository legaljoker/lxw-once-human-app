# Website additions

Changes to make on **lethalxwolf.live**. The app picks them up automatically, with no app update.

## 1. App settings file: `app-config.json`

Upload `app-config.json` to **`once-human/data/app-config.json`**.

From then on you can change the app by editing that file on the site:

- `games.oncehuman` / `games.aniimo` → `announcement`: text for a banner at the top of that game's Timers tab (`""` hides it).
- `games.aniimo.season.items`: the Aniimo **season and banner** cards. When a new banner starts, change its `name`
  and `endUtc`. Items whose `endUtc` has passed hide themselves.
  (The hub page currently shows *Forest of Butterfly Dream*, which ended Oct 30, 01:00 UTC.)
- `timers`, `tools`, `servers`, `creators`, `communityLinks`, `support`, `ravensjest`: the same lists the app has built in.
  Each list replaces the built-in one, so keep every entry when you edit.

Once Human's battle pass and loot crates need nothing new: the app already reads `battlepass.json` and `lootcrates.json`.

## 2. Phone-friendly Once Human interactive map

Problem: on phones the Loot Finder panel covers most of the map.
Fix: the panels dock to the bottom of the screen and start collapsed. Tap **Loot Finder** to open it. Desktop is unchanged.

1. Upload `interactive-map-mobile.css` and `interactive-map-mobile.js` to `once-human/`.
2. In `once-human/interactive-map.html`, add this line just before `</head>`:
   ```html
   <link rel="stylesheet" href="interactive-map-mobile.css?v=1">
   ```
3. And this line just before `</body>`:
   ```html
   <script src="interactive-map-mobile.js?v=1"></script>
   ```

## 3. Phone-friendly Aniimo interactive map

Problem: on phones the search, pin size and area list stack *above* the map, so you have to scroll a long way to reach it.
The page already has a "theater mode" that puts the map first. This change turns it on by default for screens
narrower than 900px. People can still switch it off with the theater button, and their choice is remembered.

In `aniimo/Interactive Map.dc.html`, find this line (about line 353):

```js
    else { try { if (localStorage.getItem('lxw-map-wide') === '1') this.setState({ wide: true }); } catch (e) {} }
```

and replace it with:

```js
    else { try { const w = localStorage.getItem('lxw-map-wide'); if (w === '1' || (w === null && window.innerWidth < 900)) this.setState({ wide: true }); } catch (e) {} }
```

If that page is regenerated by your page editor, re-apply the change afterwards.
